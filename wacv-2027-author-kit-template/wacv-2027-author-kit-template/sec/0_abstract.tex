\begin{abstract}
Class-conditional conformal prediction calibrates a separate score threshold for every class
and therefore requires labelled calibration examples of every class. In long-tailed
deployments these examples are precisely what is missing, as most rare classes are consumed
by training and are left with few or no held-out examples. Existing class-conditional methods
are then either undefined for such a class or fall back to the shared marginal threshold. We
ask whether the per-class correction can instead be predicted from descriptors of the class
that require no labels at all.
%
We propose Predicted Class Correction (PCC), which regresses the offset between the per-class
and the marginal conformal quantile on geometric descriptors of the classifier head, shrinks
the prediction by a scalar selected on the labelled classes, and refits a single marginal
offset. The descriptors are functions of the model's weights, so a class with zero
calibration examples still receives a threshold specific to it, and only one scalar is
calibrated, so the marginal coverage guarantee is retained (Prop.~\ref{prop:marginal}).
%
On ImageNet, PCC improves worst-class coverage on such classes by $0.075$ at matched average
set size, $70\%$ of an oracle that observes the test labels, while the strongest of eight
competitors gains $0.027$ and two are undefined on all $300$ of them. The improvement
persists with only $100$ labelled classes out of $1000$.
%
We also study where the approach stops working, and find the limit to be a property of the
evaluation set: below roughly $35$ test examples per class the oracle ceiling itself falls to
zero, so no method can be shown to help. Restricting evaluation to classes above that
threshold recovers a significant improvement on Pl@ntNet-300K, where the effect had appeared
absent.
\end{abstract}
